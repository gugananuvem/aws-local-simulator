# S3 (Simple Storage Service)

## Visão Geral

Amazon S3 (Simple Storage Service) é um serviço de armazenamento de objetos altamente escalável e durável. O simulador local oferece compatibilidade completa com a API do S3, permitindo desenvolver e testar aplicações que usam buckets, objetos, presigned URLs e websites estáticos, tudo localmente sem custos.

**Principais Features:**
- Criação e gerenciamento de buckets
- Upload, download e deletar objetos
- Presigned URLs com assinatura AWS Signature V4
- Hospedagem de websites estáticos
- Paginação e listagem de objetos
- Suporte a metadados e tags de objetos

## Porta e Endpoint

**Porta Padrão:** `4566`  
**URL Base:** `http://localhost:4566`  
**Admin API:** `http://localhost:4566/__admin/buckets`

## Quick Start

### 1. Criar um Bucket

```bash
aws s3 mb s3://my-bucket --endpoint-url http://localhost:4566
```

### 2. Upload de Arquivo

```bash
aws s3 cp myfile.txt s3://my-bucket/myfile.txt --endpoint-url http://localhost:4566
```

### 3. Listar Objetos

```bash
aws s3 ls s3://my-bucket --endpoint-url http://localhost:4566
```

### 4. Download de Arquivo

```bash
aws s3 cp s3://my-bucket/myfile.txt ./myfile.txt --endpoint-url http://localhost:4566
```

### 5. Deletar Objeto

```bash
aws s3 rm s3://my-bucket/myfile.txt --endpoint-url http://localhost:4566
```

## Operações Básicas

### Listar Buckets

```bash
aws s3 ls --endpoint-url http://localhost:4566
```

**Via cURL:**
```bash
curl http://localhost:4566/__admin/buckets
```

### Criar Bucket com Região

```bash
aws s3api create-bucket \
  --bucket my-bucket \
  --region us-east-1 \
  --endpoint-url http://localhost:4566
```

### Descrever Bucket

```bash
aws s3api head-bucket --bucket my-bucket --endpoint-url http://localhost:4566
```

### Deletar Bucket (vazio)

```bash
aws s3 rb s3://my-bucket --endpoint-url http://localhost:4566
```

### Deletar Bucket (com objetos)

```bash
aws s3 rm s3://my-bucket --recursive --endpoint-url http://localhost:4566
aws s3 rb s3://my-bucket --endpoint-url http://localhost:4566
```

### Upload de Múltiplos Arquivos

```bash
aws s3 cp ./local-dir s3://my-bucket --recursive --endpoint-url http://localhost:4566
```

### Download de Múltiplos Arquivos

```bash
aws s3 cp s3://my-bucket ./local-dir --recursive --endpoint-url http://localhost:4566
```

### Listar Objetos com Prefixo

```bash
aws s3 ls s3://my-bucket/documents/ --endpoint-url http://localhost:4566
```

### Obter Tamanho do Bucket

```bash
aws s3 ls s3://my-bucket --recursive --summarize --endpoint-url http://localhost:4566
```

## Presigned URLs

Presigned URLs são URLs assinadas temporariamente que permitem acesso a objetos S3 sem credenciais AWS permanentes. Ideais para compartilhamento seguro de arquivos e uploads diretos do navegador.

### Gerar URL de Download (GET)

```bash
curl -X POST http://localhost:4566/__admin/presigned-urls/get \
  -H "Content-Type: application/json" \
  -d '{
    "bucket": "my-bucket",
    "key": "documents/report.pdf",
    "expiresIn": 3600
  }'
```

**Resposta:**
```json
{
  "presignedUrl": "http://localhost:4566/my-bucket/documents/report.pdf?X-Amz-Algorithm=AWS4-HMAC-SHA256&...",
  "expiresIn": 3600,
  "expiresAt": "2026-09-30T20:00:00.000Z"
}
```

### Usar URL de Download

```bash
curl -O "http://localhost:4566/my-bucket/documents/report.pdf?X-Amz-Algorithm=AWS4-HMAC-SHA256&..."
```

### Gerar URL de Upload (PUT)

```bash
curl -X POST http://localhost:4566/__admin/presigned-urls/put \
  -H "Content-Type: application/json" \
  -d '{
    "bucket": "my-bucket",
    "key": "uploads/user-photo.jpg",
    "contentType": "image/jpeg",
    "expiresIn": 1800
  }'
```

### Upload Usando URL Presignada

```bash
curl -X PUT \
  -H "Content-Type: image/jpeg" \
  --data-binary @photo.jpg \
  "http://localhost:4566/my-bucket/uploads/user-photo.jpg?X-Amz-Algorithm=AWS4-HMAC-SHA256&..."
```

### Gerar URL de Exclusão (DELETE)

```bash
curl -X POST http://localhost:4566/__admin/presigned-urls/delete \
  -H "Content-Type: application/json" \
  -d '{
    "bucket": "my-bucket",
    "key": "files/temp.txt",
    "expiresIn": 300
  }'
```

### POST Policy para Upload em Formulário HTML

```bash
curl -X POST http://localhost:4566/__admin/presigned-urls/post-policy \
  -H "Content-Type: application/json" \
  -d '{
    "bucket": "user-uploads",
    "key": "avatars/${timestamp}-${filename}",
    "expiresIn": 900,
    "conditions": [
      ["content-length-range", 0, 5242880],
      ["starts-with", "$Content-Type", "image/"]
    ]
  }'
```

### Validar URL Presignada

```bash
curl -X POST http://localhost:4566/__admin/presigned-urls/validate \
  -H "Content-Type: application/json" \
  -d '{
    "url": "http://localhost:4566/my-bucket/file.pdf?X-Amz-Algorithm=AWS4-HMAC-SHA256&...",
    "method": "GET"
  }'
```

## Website Estático

### Configurar Bucket para Hosting Estático

```bash
# 1. Criar bucket
aws s3 mb s3://my-website --endpoint-url http://localhost:4566

# 2. Adicionar política de acesso público
aws s3api put-bucket-policy \
  --bucket my-website \
  --policy '{
    "Version": "2012-10-17",
    "Statement": [{
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-website/*"
    }]
  }' \
  --endpoint-url http://localhost:4566

# 3. Habilitar website hosting
aws s3 website s3://my-website \
  --index-document index.html \
  --error-document error.html \
  --endpoint-url http://localhost:4566
```

### Upload de Arquivos HTML/CSS/JS

```bash
aws s3 cp index.html s3://my-website/index.html --endpoint-url http://localhost:4566
aws s3 cp style.css s3://my-website/style.css --endpoint-url http://localhost:4566
aws s3 cp script.js s3://my-website/script.js --endpoint-url http://localhost:4566
```

### Acessar Website

```bash
# Via S3 website endpoint
curl http://localhost:4566/website/my-website/

# Ou direto pelo bucket
curl http://localhost:4566/my-website/index.html
```

## Exemplos de Uso

### Exemplo 1: Aplicação Node.js com S3

```javascript
const { S3Client, PutObjectCommand, GetObjectCommand } = require("@aws-sdk/client-s3");

const s3 = new S3Client({
  endpoint: "http://localhost:4566",
  region: "us-east-1",
  credentials: {
    accessKeyId: "test",
    secretAccessKey: "test"
  }
});

// Upload de arquivo
async function uploadFile(bucket, key, body) {
  const command = new PutObjectCommand({
    Bucket: bucket,
    Key: key,
    Body: body,
    ContentType: 'application/json'
  });
  
  return await s3.send(command);
}

// Download de arquivo
async function downloadFile(bucket, key) {
  const command = new GetObjectCommand({
    Bucket: bucket,
    Key: key
  });
  
  const response = await s3.send(command);
  return response.Body.transformToString();
}

// Usar
await uploadFile('my-bucket', 'data.json', JSON.stringify({ name: 'John' }));
const content = await downloadFile('my-bucket', 'data.json');
console.log(content);
```

### Exemplo 2: Presigned URL para Upload do Navegador

```javascript
// Backend (Node.js/Express)
app.post('/api/upload-url', async (req, res) => {
  const response = await fetch('http://localhost:4566/__admin/presigned-urls/put', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      bucket: 'user-uploads',
      key: `avatars/${Date.now()}.jpg`,
      contentType: 'image/jpeg',
      expiresIn: 1800
    })
  });
  
  const data = await response.json();
  res.json(data);
});

// Frontend (JavaScript)
document.getElementById('uploadBtn').addEventListener('click', async () => {
  const file = document.getElementById('fileInput').files[0];
  
  // Obter URL presignada do backend
  const urlResponse = await fetch('/api/upload-url');
  const { presignedUrl } = await urlResponse.json();
  
  // Upload direto para S3
  const uploadResponse = await fetch(presignedUrl, {
    method: 'PUT',
    headers: { 'Content-Type': 'image/jpeg' },
    body: file
  });
  
  if (uploadResponse.ok) {
    console.log('✅ Upload successful!');
  }
});
```

### Exemplo 3: Backup Automático

```bash
#!/bin/bash

BUCKET="backups"
TIMESTAMP=$(date +%Y-%m-%d_%H-%M-%S)

# Criar bucket se não existir
aws s3 mb s3://${BUCKET} --endpoint-url http://localhost:4566 2>/dev/null

# Fazer backup de diretório local
aws s3 cp ./important-files s3://${BUCKET}/backup-${TIMESTAMP}/ \
  --recursive \
  --endpoint-url http://localhost:4566

echo "✅ Backup criado: s3://${BUCKET}/backup-${TIMESTAMP}/"
```

### Exemplo 4: Sync de Diretórios

```bash
# Sincronizar local para S3
aws s3 sync ./webapp s3://my-website \
  --delete \
  --endpoint-url http://localhost:4566

# Sincronizar S3 para local
aws s3 sync s3://my-website ./webapp \
  --delete \
  --endpoint-url http://localhost:4566

# Syncronizar apenas extensões específicas
aws s3 sync ./src s3://my-bucket/code \
  --exclude "*" \
  --include "*.js" \
  --endpoint-url http://localhost:4566
```
