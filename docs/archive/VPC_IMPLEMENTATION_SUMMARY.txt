================================================================================
                        COMO USAR - QUICK START
================================================================================

1. INICIAR SIMULADOR
   $ npm start
   VPC disponível em http://localhost:4014

2. CRIAR VPC
   $ curl -X POST http://localhost:4014/__admin/vpcs/create \
     -d '{"CidrBlock":"10.0.0.0/16"}'

3. CRIAR SUBNET
   $ curl -X POST http://localhost:4014/__admin/subnets/create \
     -d '{"VpcId":"vpc-xxxxx","CidrBlock":"10.0.1.0/24","AvailabilityZone":"us-east-1a"}'

4. CRIAR IGW E ANEXAR
   $ curl -X POST http://localhost:4014/__admin/internet-gateways/create
   $ curl -X POST http://localhost:4014/__admin/internet-gateways/igw-xxxxx/attach \
     -d '{"VpcId":"vpc-xxxxx"}'

5. CRIAR ROUTE TABLE E ADICIONAR ROTA
   $ curl -X POST http://localhost:4014/__admin/route-tables/create \
     -d '{"VpcId":"vpc-xxxxx"}'
   $ curl -X POST http://localhost:4014/__admin/route-tables/rtb-xxxxx/routes \
     -d '{"DestinationCidrBlock":"0.0.0.0/0","Target":"igw-xxxxx","TargetType":"igw"}'

6. EXEMPLO COMPLETO
   $ node examples/vpc-example.js

================================================================================
                        CONFIGURAÇÃO
================================================================================

Em aws-local-simulator.json:

{
  "services": {
    "vpc": true
  },
  "vpc": {
    "vpcs": [
      {
        "CidrBlock": "10.0.0.0/16",
        "Tags": [{"Key": "Name", "Value": "main-vpc"}]
      }
    ]
  }
}

Variáveis de Ambiente:
  AWS_LOCAL_SIMULATOR_VPC=true           (Habilitar/desabilitar)
  AWS_LOCAL_SIMULATOR_VPC_PORT=4014      (Porta - padrão 4014)
