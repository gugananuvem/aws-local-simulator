                            COMO COMEÇAR
================================================================================

1. INICIAR O SIMULADOR:
   $ npm start

2. VERIFICAR SAÚDE:
   $ curl http://localhost:4014/__admin/health

3. EXECUTAR EXEMPLO:
   $ node examples/vpc-example.js

4. CRIAR VPC (manual):
   $ curl -X POST http://localhost:4014/__admin/vpcs/create \
     -d '{\"CidrBlock\":\"10.0.0.0/16\"}'

5. LER DOCUMENTAÇÃO:
   - QUICK_START_VPC.md (comece aqui!)
   - VPC_TEST_GUIDE.md (referência completa)
